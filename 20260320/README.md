# 《夢幻新誅仙》4週年「永夜賽季」改版活動網頁 (20260320)

《夢幻新誅仙》(MHXZX) 4 週年改版活動網頁。活動分為「預約新賽季」登入禮與「永夜將至，決戰將起」陣營對抗全服累積獎勵兩大玩法，授權者可邀請好友為所屬陣營累積擊殺進度，獲取專屬稱號、武魂、綁元、名師禮包等獎勵。

- 正式網址：https://xxa.iwplay.com.tw/event/fifth.anniversary.html
- 活動一時間：2026/3/20 － 2026/4/20
- 活動二累積期：即日起至 2026/3/27 23:59，獎勵結算將於 3/26 改版維護後發送
- 網頁查詢開放至 2026/4/30 23:59

## 活動玩法

- **KV 主視覺與浮水印導覽**：頁面側邊／行動版底部常駐浮水印列（`fixed_nav_pc` / `noke_flex_sp`），提供官網、遊戲下載、官方 FB 捷徑；KV 區以 Parallax.js 做角色立繪的滑鼠視差效果。
- **活動一：預約新賽季（`event01`）**：2026/3/20－2026/4/20 期間首次登入會員帳號即可領取「深空夜襲禮包」，3/26 改版後再加贈 4 週年限定「逐光者套裝」與坐騎「夢豬」；登入後畫面由「登入前」（`.login`）切換為「恭喜獲得」（`.login_after`），並保留登出按鈕可重置回登入前畫面以供測試。
- **活動二：永夜將至，決戰將起（`event2`）**：玩家先從兩大陣營擇一加入（`#rock_cumulative_modal` / `#rock_cumulative_modal2` 彈窗確認選擇），選定後顯示陣營 BOSS 累積血條，血條下方對應 6 個階段的全服累積獎勵；玩家可透過 Line／Facebook／複製連結分享邀請，每日登入可獲得攻擊次數，每日成功邀請最多 3 位好友可再獲取最多 4 次攻擊機會（次數每日 00:00 重置）。
- **活動三：版本預告翻書區（`event3`）**：5 本可翻閱的「書本」卡片，點擊後觸發翻頁動畫並彈出對應版本預告圖，搭配「獎勵查詢」與「活動規則」兩顆按鈕彈窗。
- **其他彈窗**：邀請好友彈窗（`#invite`）、恭喜獲得／成功彈窗（`#reward`）、累積獎勵一覽表（`#reward_list`）、獎勵序號查詢列表（`#inquire`，含複製序號按鈕）、活動規則與注意事項（`#notice`）、未登入提示（`#eventAlertModal`）。

## 核心技術實作

- **Demo 模擬登入（`js/emma_demo.js`）**：點擊「立即登入」按鈕切換顯示「恭喜獲得深空夜襲禮包」畫面，點擊「登出」還原登入前畫面，供測試切換會員登入狀態。
- **翻書互動（`js/main.js`）**：點擊任一本書（`.book_mm`）先加上 `active` class 觸發翻頁動畫，再以 `setTimeout` 延遲 0.5 秒待動畫播放完畢後才彈出 `#book_open_modal` 燈箱，並依點擊的書本編號（`.book_up1`～`.book_up5`）動態替換燈箱內圖片 `src`（先清空再賦值避免瀏覽器沿用快取舊圖）；關閉燈箱時統一收回所有書本的 `active` 狀態。
- **BOSS 血條進度**：PC 版以 `margin-right` 百分比、行動版以 `clip-path: inset()` 控制血條裁切範圍呈現目前全服累積進度，目前為 demo 寫死起始數值，正式串接時改由後端回傳的累積數值計算。
- **文案集中管理（`js/20260320.js` 的 `ViewObj`）**：社群連結、活動一／二文案、陣營累積獎勵列表（`event2_reward_list`）、活動規則（`event2_rule`）與注意事項（`notice`）皆集中管理，對應 HTML 中 `{xxx}` 樣板字串與各彈窗內容。
- **視差滾動效果**：KV 區以 `Parallax.js` 針對 3 層角色立繪（`.layer.role_1/2/3`）設定不同 `data-depth`，營造滑鼠移動時的景深視差效果，並搭配 `wow.js` 做區塊進場淡入動畫。

## 版面規格 / RWD

- 採用 Bootstrap 固定斷點式響應設計（主要在 1100px／991.98px／768px／767px／575.98px，另有 376px／340px 小尺寸手機微調），各區塊依寬度調整字級、間距與排版。
- KV Slogan、活動一標題圖等以 `<picture>` 切換桌機／手機版圖檔；BOSS 血條則以 Bootstrap 的 `d-none d-md-block` / `d-md-none` 切換桌機（`margin-right` 控制血量）與行動版（`clip-path` 控制血量）兩套獨立樣式。
