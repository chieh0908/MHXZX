# 《夢幻新誅仙》官方網站

《夢幻新誅仙》(MHXZX) 官方網站首頁。本次更新（261001，魔神殿版本）於版本亮點輪播新增「全新門派 魔神殿登場」等 5 個版本預告分頁，並更新首頁主視覺與自動彈窗廣告，導流至「魔神殿」活動頁。

- 正式網址：https://www.mhxzx.com.tw/

## 遊戲背景

旗艦仙俠鉅作《夢幻新誅仙》，改編自經典誅仙世界觀，重視原作還原與多元玩法體驗，結局走向由玩家自行決定；主打極致 PC 端畫質、動態光源 PBR2.0 技術，搭載杜比全景音效呈現誅仙世界。

## 頁面內容

- **側邊欄（`aside`）**：社群連結（Facebook／YouTube／Telegram）、QR Code 下載，以及可收合展開的版本福利／預約宣傳圖。
- **Header**：Logo、Slogan、底部下載區（Google Play／App Store／台灣與香港 APK 下載、QR Code、安裝須知）。
- **版本亮點輪播（`version`）**：5 個分頁依序介紹「全新門派 魔神殿登場」「賽季靈獸 九兒免費送」「全新賽季 獸潮來襲」「全新坐騎 三眼魔猴」「全新玩法 天道棋局」，每個分頁各有介紹圖與文字說明。
- **情報速遞（`news`）**：輪播廣告 Banner＋最新消息列表，並連結官方 Facebook 與巴哈姆特哈拉板。
- **門派介紹（`menpai`）**：11 個門派／角色輪播卡片（青雲門、焚香谷、鬼王宗、天音寺、合歡派、南疆古巫、長生堂、萬毒門、鬼道、天道府、寒風龍族），切換門派頁籤時才動態載入對應介紹影片。
- **遊戲特色輪播（`features`）**：商城／特色宣傳圖輪播。
- **GameInfo／Footer**：由遠端共用元件（`ids.iwplay.com.tw`）動態載入。
- **自動彈窗廣告（`#pop-up-ads`）**：進站自動彈出的活動宣傳圖，點擊導流至魔神殿活動頁。

## 版面規格 / RWD

- 採用 Bootstrap 固定斷點式響應設計（主要在 1300px／991.98px／767.98px／575.98px），各區塊依寬度調整字級、間距與排版，480px 以下另有數個小尺寸手機的細部微調。
- Header、側邊欄等主視覺區塊以 `d-none d-lg-block` 等 class 切換桌機／手機版圖源；門派介紹影片則是切換門派頁籤時才動態寫入 `<video>` 的 `src`，不會一次預載全部 11 支影片。
